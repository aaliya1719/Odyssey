# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default branch. Older versions may not receive updates.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the maintainer privately through the security contact configured in the repository hosting settings and include:

- A description of the issue and its impact.
- Steps to reproduce or a minimal proof of concept.
- The affected commit, version, or deployment.
- Any suggested mitigation.

Allow reasonable time for investigation and a fix before public disclosure. Do not include real user data, API keys, passwords, or service-role credentials in a report.
